# pyretry
Copy @retry

## Требования:
Реализовать свою версию декоратора @retry

1. Оборачивает любую функцию
2. Можно задать количество перезапусков
3. Можно указать сколько ждать перед повторным запуском 
4. Можно указать какие ошибки вызывают перезапуск
5. Можно подавить финальное исключение или выбросить его обратно 
6. Можно добавить функции, которые будут выполняться в зависимости от сценария: перед ретраем, после ретрая 
7. Можно испольозовать в for

## Пользовательские истории
1. Навешивание без указания параметров сделает 5 ретраев для любого вылетевшего Exception. Перед перезапуском вызовется стандартное логирование.
2. Если указать `max_retries: int` - Максимальное количество перезапусков не привысит заданное значение
3. Если указать `retry_exceptions: list[tupe[Exception]]` - Перезапуски будут стартовать только при условии выбрасывания указанных исключений
4. Если указать `reraise_exception: bool = True` - При `True` (по-умолчанию) после макисмального числа повторных попыток исключение будет выбрашено наверх. Если указанно `False`  значение будет подавлено.
5. Если указать `wait_seconds_before: float` - Перед перезапуском програма уснет на указанное значение секунд
6. `callback_before: Callable[..., ...]` - Функция, которая будет вызвана перед перезапуском. В нее передается функция, ошибка и параметры функции вызвавшые ошибку
7. `callback_after: Callable[..., ...]` - Функция, которая будет вызвана после перезапуском. В нее передается функция, и параметры запуска
8. Функционал можно применить к `for :... with:...` для перезапусков итераций
